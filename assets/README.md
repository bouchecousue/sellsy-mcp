# Repository illustration

- `sellsy-mcp-illustration.png`: generated artwork with the "by BoucheCousue"
  author credit, 1774 × 887 pixels.
- `social-preview.jpg`: lightweight JPEG export of the same artwork for the README
  and GitHub repository social preview, 1774 × 887 pixels, 2:1 aspect ratio.
- `illustration-prompt.txt` and `illustration-credit-prompt.txt`: creation and
  credit-edit prompts used with the built-in image generation tool on
  5 November 2026. The illustration was visually reviewed for spelling,
  composition and the absence of customer data or official brand logos.

The image represents a community connector between CRM records and AI clients.
It is a project illustration, not an official Sellsy logo or a technical diagram.
The repository's MIT license applies to these project assets as applicable.

To use the preview on GitHub, upload `social-preview.jpg` under repository
**Settings → General → Social preview**. Referencing the file in the README
does not configure GitHub's social preview setting.
